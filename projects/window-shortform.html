창호 홍보 숏츠 기획·제작

낡고 흔들리는 창의 불편을 사계절로 보여주고, 시공 장면까지 이어지는 숏츠를 AI 영상 도구 두 개로 만들었습니다.

어디서 · 무슨 일
BX컨설팅 인턴 · 창호 시공 업체의 유튜브 숏츠·릴스용 홍보 영상. 아파트·주택에 사는 일반 소비자가 보는 영상입니다.
주어진 과제
창호 시공 업체를 알리는 숏츠를 만들면서, 첫 장면부터 문구가 아니라 "우리 집 창 같다"는 느낌이 먼저 들게 하고 싶었습니다. 낡고 흔들리는 창을 첫 장면으로 정한 이유입니다.
내 역할
콘셉트·기획·스토리보드, 장면 이미지와 생성 프롬프트 작성·승인, 영상 생성과 편집. 아이디어는 AI와 동료 직원과 이야기하다 제가 정했고, 편집·후처리 스크립트는 AI 에이전트(Claude Code 등)와 함께 만들었습니다.
결과
25.7초, 1080×1920 세로 영상 1편. 아직 고객에게 전달하지 않은 내부 제작물이라 조회수나 반응 수치는 없습니다. 아래 영상은 업체명이 나오는 엔딩을 뺀 22초 분량입니다.
이 경험으로 할 수 있는 일
제품 문제를 첫 장면으로 보여주는 숏폼 광고를 기획하고, 생성 비용이 드는 컷과 편집으로 처리할 컷을 나눠 제작 범위를 정할 수 있습니다.

기획 흐름

  1. 콘셉트 정하기AI와 동료 직원과 아이디어를 주고받다가 낡고 흔들리는 옛 구축 아파트·주택의 창이 떠올랐습니다. 그 창이 일 년 내내 주는 불편을 한 장면씩 보여주기로 했습니다.
  2. 사계절로 나누기봄은 틈새 바람, 여름은 빗물 누수, 가을은 날벌레와 낙엽, 겨울은 결빙으로 잡았습니다. 어느 계절에 보더라도 우리 집 이야기로 읽히게 하려는 구성입니다.
  3. 같은 창가 하나로 통일장면마다 공간을 바꾸면 생성 비용이 늘고 영상이 흩어집니다. 같은 창가에서 계절만 바꾸기로 했습니다.
  4. 스토리보드 12컷문제 → 얼음 균열 → 철거·시공 → 작동 확인 → 평온한 사계절 → 마무리로 20초 안에 짰습니다. 장면 이미지는 한 장씩 보고 승인했습니다.
  5. 생성 길이와 편집 길이 나누기생성 도구(Seedance 2.5)의 최소 길이가 4초라 컷마다 "생성 길이"와 "편집에서 쓰는 길이"를 표로 따로 적었습니다. 새로 생성할 컷과 기존 영상·이미지를 편집으로 처리할 컷을 여기서 갈랐고, 유료 생성은 견적을 확인하고 승인한 뒤에만 실행했습니다.
  6. 도구 나눠 쓰기처음에는 Google Flow를 연습용으로만 쓰고 생성은 Seedance 2.5로 하려고 했습니다. 그런데 Flow 결과물이 괜찮아서 사계절 앞부분과 후킹 뒤 커튼 전환은 Flow 것을 썼습니다. Seedance 2.5는 창짝이 흔들리는 후킹 4초와 겨울 시공 장면에 썼고, 시안 중 일부는 형태가 뒤틀리거나 원하는 방향으로 나오지 않아 쓰지 못했습니다.

스토리보드

20초 스토리보드 v2에서 앞 8컷을 가져왔습니다. 컷마다 편집 시간과 생성 방식을 적었습니다.

기획스토리보드 v2: 문제 → 균열 → 철거·시공 → 작동 확인

만들며 풀어야 했던 것

  1. 생성 중 형태가 변함Google Flow로 시작·종료 이미지 두 장을 잇는 카메라 동선을 연습했는데, 후반에 창짝이 열리고 없던 손잡이가 생겼습니다. 종료 이미지가 화분을 다른 모양으로 다시 그린 것도 한 원인으로 봤고, 종료 이미지를 화분이 프레임 밖으로 나가는 구도로 새로 만들었습니다. 다만 이 방법은 오류를 줄이는 설계일 뿐 물체를 고정해 주지는 않아서, 생성 전에 두 이미지의 형태 차이를 먼저 확인했습니다.
  2. 따로 만든 구간의 이음새앞 사계절과 뒤 시공 영상은 따로 만들어 창 위치와 크기가 조금 달랐고, 이어 붙이면 화면이 옮겨 가는 느낌이 남았습니다. 창 좌표를 맞춰 다시 보정했고, 인물 위에 겹쳐 보이던 균열 합성 효과는 걷어냈습니다. 생성 해상도(720p) 차이로 7~8초 부근에서 화질이 떨어지는 문제도 보정했지만, 원본 화질을 복원한 것은 아닙니다.
  3. 첫 장면 정하기후킹은 겨울 창 문구형, 사계절 예고편형, 화분이 들어왔다 나가는 편집 시안까지 여러 안을 놓고 봤습니다. 최종은 창짝이 흔들리며 틀어지는 장면입니다. 4초 생성 견적이 1080p 최대 364크레딧, 720p 최대 148크레딧으로 나와, 영상을 만들기 전에 4컷 스케치로 구도를 먼저 정하고 720p로 생성했습니다.
  4. 후킹에서 본편으로 넘어가는 전환후킹 마지막 프레임과 본편 첫 프레임을 시작·종료 프레임으로 넣고 커튼이 화면을 가리는 전환을 Flow로 만들었습니다. 커튼 이동 속도가 구간마다 달라 보여서 일정하게 맞추는 작업을 여러 번 반복했습니다.
  5. 소리와 화질덜컹이는 소리와 새소리가 겹치고 배경음이 끊기는 구간이 있어 효과음을 분리하고 배경음은 이어서 다시 배치했습니다. 나레이션 간격과 자막 위치도 영상에 맞춰 조정했습니다. 흐린 구간은 무료 업스케일 도구의 라이선스(상업 사용 가능 여부)를 먼저 확인하고, 짧은 샘플로 비교해 AI 업스케일을 적용했습니다.

단계마다 버전을 남겨 v36까지 갔고, 중간 산출물과 비교 자료는 작업 폴더에 그대로 보관하고 있습니다.

돌아보며

모델이 좋아도 제가 무엇을 원하는지 상세하게 적지 않으면 원하는 영상이 나오지 않았습니다. 쓰지 못한 Seedance 시안 중 여러 개가 그 경우였습니다. 지시를 구체적으로 쓰는 것이 도구 성능만큼 중요하다는 것을 이 작업에서 배웠습니다.
