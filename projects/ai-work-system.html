여러 AI가 같은 규칙으로 일하는 업무 폴더

회사 업무에 Claude Code, Codex, Antigravity를 번갈아 쓰다 보니 도구마다 규칙이 달라 같은 설명을 반복해야 했습니다. 업무 폴더 하나에 공용 스킬 원본과 작업 규칙을 두고, 어느 도구로 열어도 같은 방식으로 일하게 묶었습니다. 지금도 매일 이 환경에서 일합니다.

배경

행사 자료 검수, 보고서 장표 수정, CRM 구축처럼 성격이 다른 업무를 AI와 함께 하면서, 도구를 바꿀 때마다 같은 맥락을 다시 설명하고 같은 실수를 다시 고쳐야 했습니다.

판단

AI에게 매번 잘 묻는 것보다, AI가 매번 같은 규칙을 읽고 시작하게 만드는 편이 낫다고 봤습니다. 그래서 규칙과 반복 작업을 문서로 남기고, 사람이 승인해야 하는 지점을 따로 정했습니다.

만든 것
  • 공용 스킬 원본: 스킬을 한 폴더에서만 고치고, 각 도구에는 연결만 걸어 도구마다 복사본이 달라지지 않게 함. 직접 만든 스킬(브로셔 검수, 제안서 작성)과 외부에서 골라 받은 스킬을 함께 관리
  • 작업 규칙 문서: 필요한 파일만 읽기, 같은 확인 반복하지 않기, 작업이 끝나면 다음 할 일을 한 문장으로 남기기
  • 승인 게이트: 커밋·운영 DB 반영·배포·외부 발송은 사람이 따로 승인해야 진행
  • 역할 분리: CRM 작업에서는 기획·UX 설계·구현·검수 에이전트를 나눠, 검수가 반려하면 구현으로 되돌아가게 함
  • 모델 추천 훅: 요청 성격에 따라 상위 모델이 필요한지 알려주는 장치를 붙여 비용이 큰 모델을 필요할 때만 쓰게 함
  • 정리: 쓰지 않는 스킬 8개를 보관 폴더로 옮겨, AI가 매번 읽는 분량을 줄임
결과

검수 스킬과 CRM 프로토타입 모두 이 환경에서 만들었습니다. 새 대화를 열어도 AI가 같은 규칙에서 출발해 설명을 반복하는 일이 줄었고, 되돌리기 어려운 작업은 항상 제 승인을 거칩니다. 개인 환경이라 절감 시간을 따로 측정하지는 않았습니다.

한계

코드와 설정 파일은 모두 AI가 작성했고, 저는 구조를 정하고 결과를 확인했습니다. 팀 단위로 배포한 적은 없는 개인 업무 환경입니다.
