CRM 체험 페이지

공개 홈페이지의 CRM 예시에 C안 디자인과 최소 모션을 적용하고 저장소에 반영했습니다.

main 반영, 배포는 권한 대기

이미지 슬라이드 홈을, 모션 중심 홈으로

현재 홈페이지의 문구와 서비스 7개는 그대로 쓰고, 고객사 의사결정자에게 "한 팀이 전부 해결한다"는 인상을 주는 홈을 제안했습니다.

정한 것

  • 벤치마크를 바꿔 두 시안을 만들었습니다. 1차는 어두운 바탕의 스크롤 연출, 2차는 다른 사례를 기준으로 밝은 바탕으로 다시 만들고, 둘의 장점을 합쳐 C안으로 정리했습니다.
  • 뼈대는 그대로 둡니다. 홈의 일곱 섹션 순서와 CMS, 문의 기능은 바꾸지 않고 배치와 모션만 제안했습니다.
  • 문구는 현재 홈페이지 원문 기준입니다. 새로 쓴 문구는 따로 표시해 승인을 받도록 했습니다.

보고서로 분리한 것

  • 변경 수준. 일곱 섹션 중 세 개는 새로 제작, 네 개는 겉모습과 배치 변경입니다.
  • 승인이 필요한 네 가지. 삭제 항목 3건, 새 소개 문구, 외부 라이브러리 3종(GSAP, ScrollTrigger, Lenis), 밝은 바탕과 어두운 바탕 선택입니다.

산업별 세일즈 교육, 세 산업을 서비스 앞 메뉴로

전문 강사를 섭외해 신규 산업 교육 시장을 여는 구상을 홈페이지에서 소개하는 페이지입니다. 영업본부장과 사업부장이 먼저 읽는다고 보고, 산업의 현재와 전망, BX의 관점, 기여 영역, 관련 경험, 대표 교육안, 현업 적용 순으로 구성했습니다.

지킨 원칙

  • 만들어내지 않기. 세 산업 모두 직접 수행사례가 없고 확정된 강사도 없습니다. 공통 경험은 범위를 표기해 쓰고, 산업 실적과 강사는 지어내지 않았습니다.
  • 출처와 해석 분리. 산업 배경은 공개 자료(IQVIA, McKinsey, SEMI)를 인용하고 BX의 해석은 따로 표시했습니다.
  • AI 이미지 표기. 산업 장면 이미지 3장은 AI로 생성했고 화면에 그렇게 밝혔습니다.

구성

  • 메뉴. 서비스 앞에 "산업"을 두고 전체보기, 제약, IT, 반도체를 하위 메뉴로 둡니다.
  • 상세 흐름. 현재와 전망, BX 인사이트, 전문성, 기여 영역, 관련 경험, 대표 교육안, 현업 적용과 문의.
  • 교육안. 실무자와 관리자를 구분하고, 반도체는 제조사와 장비·소재·부품 기업을 나눴습니다.

모션 그래픽을 여러 번 갈아엎은 과정

처음 버전은 "밋밋하고 세 산업이 같아 보인다"는 지적을 받았습니다. 스크롤 연동, 워크시트형 등을 시도한 끝에, 의사결정자가 속으로 묻는 질문에서 출발하는 지금의 방식으로 정했습니다.

검수

디자인 검수3칸 반복 도식 제거, 산업별 구조 분화, 장식 점과 보조 강조색 정리, 영문 소제목 축소, 섹션 머리글 세로 구조.
화면 UX 측정터치 영역 44px, 글자 12px 이상, 모션 안 글자 대비 4.5:1 이상, 내부 검토용 요소는 미리보기 주소에서만 표시.
운영 사이트 정합성운영 코드의 메뉴, 문의 문구, 진행 단계, 과정 목록과 대조해 용어(세일즈 교육), 문의 문구, 단계 이름, 문제별 솔루션 링크, 경험 표기와 링크, 브랜드 표기를 맞췄습니다.
동작375, 768, 1024, 1440px에서 다섯 페이지 20개 조합 가로 넘침 없음. 탭 키보드 전환, 문의 창, 모바일 메뉴, 모션 줄이기 확인.

CRM 체험 페이지에 C안 디자인과 모션

공개 홈페이지의 CRM 예시 소개와 체험 화면에 C안의 색, 알약 버튼, 카드 모양을 적용했습니다. 최소한의 모션과 기능 참고 요소를 더해 저장소에 14개 커밋으로 반영했습니다.

판단한 것

  • 되돌린 시도. 상세 슬라이드 패널과 대시보드 2단 구성을 만들어 보고 기존 구조로 되돌렸습니다. 업무 화면에서는 익숙한 아코디언이 낫다고 판단했습니다.
  • 넣지 않은 것. 이전 값이 없는 가상 데이터에는 추세 화살표를 붙이지 않았고, 단계 이동은 검증된 업무 양식을 거치도록 보드의 드래그 이동은 뺐습니다.
  • 새 라이브러리 없음. CSS와 기존 방식의 작은 스크립트만 사용했고, 모든 모션은 모션 줄이기에서 꺼집니다.

확인한 것과 막힌 것

  • 확인. 테스트 459건 통과, 타입 검사 오류 0건, 1440px와 390px 화면 확인, 모션 줄이기 상태 확인.
  • 발견해 고친 문제. 스크롤을 크게 내리면 건너뛴 패널이 보이지 않던 오류를 최종 검수에서 찾아 고쳤습니다.
  • 막힌 것. 운영 배포는 배포 도구의 접근 권한 문제로 대기 중입니다. 같은 화면은 별도 저장소의 공개 사본으로 검토할 수 있습니다.

AI와 사람이 나눠 한 일

구현 속도는 AI가 냈고, 무엇을 만들지와 무엇을 만들지 않을지는 제가 정했습니다.

AI가 한 일

  • 화면과 모션 구현(Claude Code, Codex)과 반복 수정
  • 화면 크기별 검증 스크립트, 대비·터치 영역·글자 크기 측정
  • 기획안과 검증 문서 초안, 산업 장면 이미지 3장 생성

제가 한 일

  • 방향 합의와 선택: 벤치마크 교체, 스크롤이 아닌 자동 재생, 속도와 정렬 결정
  • 사실의 경계 설정: 실적과 강사를 만들지 않고, 출처와 해석을 분리
  • 되돌림 판단: 시도해 본 화면을 직접 보고 채택과 폐기를 결정
  • 운영 사이트와의 정합성 대조를 요청하고 어긋난 항목을 정리

현재 상태와 한계

  • 운영 미반영. 홈 시안은 승인 대기, 산업별 페이지는 내부 검토본, CRM은 저장소 반영 후 배포 대기입니다.
  • 산업별 문구는 예시. 질문과 교육 구성은 공개 자료와 BX의 해석에 기반한 초안이고 해당 산업 현업의 검증을 거치지 않았습니다.
  • 실적 없음. 세 산업의 직접 수행사례와 확정 강사는 없으며, 화면에도 그렇게 표기했습니다.
  • 검증 범위. 데스크톱 브라우저 기준 검증입니다. 실제 휴대기기, Safari, Firefox는 확인하지 못했습니다. 문의 창은 실제로 전송되지 않는 미리보기입니다.
