주어진 과제
디자인팀에 제작을 맡기기 전에 콘셉트와 레이아웃을 시안으로 만들어야 했는데, 손으로 만들면 피드백마다 처음부터 다시 해야 했습니다.
내 역할
시안 기획·AI에 수정 지시·결과 확인. 코드는 직접 쓰지 않았고, 색과 문구를 변수로 빼 달라고 요청해 다시 실행하기 쉽게 했습니다.
결과
수정 요청이 오면 값만 바꿔 새 버전을 뽑았고, 기획안·의뢰서를 디자인팀에 넘겼습니다. 실제 인쇄·제작은 디자인팀이 했습니다.
이 경험으로 할 수 있는 일
교안·장표처럼 버전이 자주 바뀌는 자료를 AI가 다시 만들 수 있는 형태로 정리해, 수정 요청에 빠르게 새 버전을 낼 수 있습니다.

진행 과정

  1. 방식 바꾸기캐릭터 조합 4가지, 색 후보 여러 개를 손으로 배치하다 시간이 배로 들어, 슬라이드를 만드는 스크립트를 AI에 맡겼습니다.
  2. 슬라이드 생성PowerShell과 PowerPoint 자동화로 슬라이드를 만들고, 색 팔레트를 변수 표로 뺐습니다.
  3. 캐릭터 배치캐릭터 시트를 4분면으로 잘라 각각 배치하는 작업을 좌표 계산으로 처리하게 했습니다.
  4. 3단계 수정전체 리빌드 → 구성 확정 → 문구 미세 조정 순으로 반복하고, 매번 PNG로 바로 확인했습니다.
  5. POP·목업POP 스탠드 기획안은 python-pptx로, 인쇄 목업은 HTML/CSS/SVG로 AI가 만들었습니다.

만든 자료

function Crop-Quadrants { param([string]$Source, [string]$Prefix) $image = [System.Drawing.Image]::FromFile($Source) $halfW = [int]($image.Width / 2) $halfH = [int]($image.Height / 2) $items = @( @{ Name = 'cat'; X = 0; Y = 0 }, @{ Name = 'dog'; X = $halfW; Y = 0 }, @{ Name = 'penguin'; X = 0; Y = $halfH }, @{ Name = 'hedgehog'; X = $halfW; Y = $halfH } ) # 캐릭터 시트 한 장을 4분면으로 잘라 개별 배치 }
