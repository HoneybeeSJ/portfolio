Overview · 배경과 문제

왜 직접 만들었나

기존 LLM으로 지원 서류를 작성하는 방식은 허위 사실을 지어내는 '할루시네이션'과 획일화된 문체라는 치명적 한계가 있었습니다. 본인의 구직 활동을 혁신하기 위해, 검증된 사실만 사용하고 본인 문체를 복제하는 자동화 시스템을 직접 설계했습니다.

결과물 — 채용 공고를 입력하면 분석 → 매칭 → 초안 → 교정 → 산출물(이력서·경력기술서·자기소개서, 슬라이드·면접 대비)까지 자동 수행하는 AI 파이프라인.

Architecture · 3계층 설계

Directive · Orchestration · Execution

  • Directive Layer — 프로세스 통제, 기업별 커스터마이징 룰 및 예외 처리 가이드라인(SOP) 수립. 검증된 마스터 이력서 팩트만 사용하도록 정책 설계
  • Orchestration Layer — 직무 적합도 평가 알고리즘 설계, RAG 기반 경험 추출·검증 프로세스 조율
  • Execution Layer — 외부 웹 검색, 로컬 파일 입출력(File I/O), 데이터 전처리 등 결정론적 도구(Deterministic Tools) 연동
  • Self-annealing Loop — 생성 실패·포맷 오류를 모니터링해 가이드라인에 피드백, 시스템을 스스로 고도화하는 자가 치유 루프
Pipeline · 처리 흐름

입력 한 번, 산출물 일괄 생성

  1. 채용공고 분석 (Agent A)
    비정형 공고 텍스트에서 회사·직무·자격요건·키워드를 구조화 JSON으로 추출. 회사명이 없으면 임의 추측 금지
  2. 이력서 매칭 (Agent B)
    마스터 이력서 전체 맥락을 근거로 직무 적합도 점수와 매칭 경험 산출 — 실재하는 경험만 사용해 허위 이력 생성 방지
  3. 자소서 초안 작성
    매칭 결과와 문체 가이드를 결합해 초안 생성. 웹 자동화(ChatGPT·Claude) → API 순으로 다단계 폴백해 안정성 확보
  4. 톤앤매너 교정 (Agent C)
    스타일 가이드 기준으로 AI 상투어를 제거하고 본인 문체로 교정. 수치·성과 등 사실은 변경하지 않음
  5. 슬라이드 · 면접 대비 생성
    포트폴리오 PPTX(+Canva 연동)와 면접 예상질문·답변 가이드를 자동 생성해 지원 1건당 산출물 일괄 출력

Takeaway · 의의

'시스템 설계자적 사고'로 잇는 역량

AI 기술을 현실 문제 해결과 프로세스 혁신에 적용하는 시스템 설계자적 사고를 입증한 프로젝트입니다. 콘텐츠 설계·자동화 역량을 그대로 교육 콘텐츠 기획·운영에 적용할 수 있으며, 교육생이 자신의 실무 장벽을 AI 에이전트 설계로 해결하도록 돕는 도메인 맞춤형 AI 교육 설계의 토대가 됩니다.
