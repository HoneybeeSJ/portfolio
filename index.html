학습자 개인에게 최적화된 콘텐츠를 생성하는 AI 설계 시스템.
교수설계(ISD) 방법론을 AI로 구현한 실증 사례입니다.

Directive Layer — 학습 목표 설계

콘텐츠 생성 규칙, 어조 가이드라인, 기업별 맞춤 SOP 수립. 교육 설계의 목표 명세서(Goal Statement)에 해당.

Orchestration Layer — 학습자 맞춤화

학습자(지원자) 경험 데이터를 검색·추출해 직무 적합도를 평가하는 RAG 파이프라인. ISD의 학습자 분석(Learner Analysis)에 해당.

Execution Layer — 콘텐츠 자동 생성

실시간 웹 검색, 파일 I/O 등 결정론적 도구 연동으로 최적화된 콘텐츠를 생성. 교수설계의 개발(Development) 단계 자동화.

Self-annealing Loop — 지속적 개선

오류 감지 시 Directive를 자동 갱신. Kirkpatrick 4단계 평가 모델의 피드백 루프를 AI로 구현.
