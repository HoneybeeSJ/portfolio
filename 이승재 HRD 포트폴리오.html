① 채용공고 분석 Agent A

비정형 공고 텍스트에서 회사·직무·자격요건·키워드를 구조화 JSON으로 추출. 회사명이 없으면 임의 추측을 금지.

② 이력서 매칭 Agent B

마스터 이력서 전체 맥락을 근거로 직무 적합도 점수와 매칭 경험을 산출. 실재하는 경험만 사용하도록 프롬프트를 설계해 허위 이력 생성을 방지.

③ 자소서 초안 작성

매칭 결과와 문체 가이드를 결합해 자기소개서 초안을 생성. 웹 자동화(ChatGPT·Claude) → API 순으로 다단계 폴백해 안정성 확보.

④ 톤앤매너 교정 Agent C

스타일 가이드 기준으로 AI 상투어를 제거하고 본인 문체로 교정. 수치·성과 등 사실은 변경하지 않음.

⑤ 슬라이드 · 면접 대비 생성

포트폴리오 PPTX(+Canva 연동)와 면접 예상질문·답변 가이드를 자동 생성해 지원 1건당 산출물을 일괄 출력.
